# 拼豆图纸生成器 · MARD 221 色

一个**纯前端、零依赖**的拼豆（Perler / Hama Beads）图纸生成工具。上传图片，设好豆板尺寸，自动匹配 MARD 221 色色号，生成可打印的图纸、色号用量表和可编辑的拼豆网格。

> 图片只在本机浏览器里处理：不上传、不请求服务器、没有后端。双击 `index.html` 就能用。

## 功能

- **上传图片**：点击「上传图片」、直接拖拽到画布、或 `⌘/Ctrl + V` 粘贴剪贴板图片。支持 JPG / PNG / WebP / GIF / BMP / AVIF 等常规图片；**不读取 PDF**（PDF 请先导出为图片）。
- **自由尺寸**：
  - 右侧滑块 **5–200 孔**实时调整正方形豆板；
  - 也可以分别手动输入 **宽（列）× 高（行）**，支持 1–200 的非方形豆板；
  - 内置 14×14 / 29×29 / 40×40 / 57×57 快捷尺寸。
- **MARD 221 色**：内置完整 9 个色系（A/B/C/D/E/F/G/H/M，共 221 个色号）。
  - 「最大用色数」2–221 可调，越少越省钱，越多越接近原图；
  - 可用色板支持搜索、整组/单色启用或禁用；
  - 点色块即可取色画笔，也可以切换成「启用/禁用」模式。
- **画面调节**：
  - 明度、对比度、**饱和度滚动条（−100% ~ +100%）**，实时重新匹配；
  - 饱和度快捷按钮：原色 / 鲜艳 / 柔和 / 黑白；
  - 抖动：不抖动 / 有序抖动 / 误差扩散；
  - 可去除近白背景、保留透明区域为空。
- **适配方式**：完整适应 / 裁剪填充 / 拉伸铺满。
- **网格编辑**：画笔、橡皮、吸管；右键快速擦除；撤销 / 重做。
- **查看**：缩放、标尺、每 5/10 格加粗网格、29 孔分板线、色号叠加、拟真豆子质感。
- **用量统计**：总豆数、用色数、按 5mm 豆估算的成品尺寸、按颜色排序的用量清单；点击某一行可高亮对应格子。
- **导出**：
  - 图纸 PNG（带标尺 + 色号用量表，适合打印/A4）；
  - 纯网格 PNG；
  - 用量 CSV（Excel 可打开）；
  - 打印图纸；
  - 工程 JSON 导出 / 导入。
- **自动保存**：草稿（图纸 + 参数）存在本机 `localStorage`，刷新页面不丢；「清空重来」可重置。草稿**不保存原图**，刷新后如需按新参数重新采样，请重新上传图片（直接改尺寸会按现有网格缩放）。

## 使用提示

1. 上传图片后，先用「滑动调尺寸」把豆板调到预期尺寸（29×29 是常见标准大板）。
2. 调低「最大用色数」可以让颜色更少、更好买豆；调到 8–16 通常已经够用。
3. 想要颜色更鲜艳，拉高「饱和度」；想做黑白图纸，点「黑白」。
4. 边缘有太多细碎色块时，降低「最大用色数」会自动合并掉低频颜色。
5. 生成后可以直接在网格上补画：左键涂色、右键擦除、吸管取色，`⌘/Ctrl + Z` 撤销。
6. 用「导出 → 图纸 PNG」拿到带色号表的图纸，或用「打印图纸」直接打印。

## 数据说明

`assets/palette.js` 中的 MARD 221 色数据来自公开社区色卡整理：

- 上游：[HansBug/pindou-color-data](https://github.com/HansBug/pindou-color-data) 的 `mard-221-github` 数据集；
- 色号：A1–A26、B1–B32、C1–C29、D1–D26、E1–E24、F1–F25、G1–G21、H1–H23、M1–M15，共 221 色；
- 数据为社区复刻的**参考 RGB 值**，不是官方扫描色卡。实际购买/配色请以实物色卡为准。
- 数据源本身不包含颜色名称，因此界面中显示的是色号 + HEX。

## 技术说明

- 图片处理：Canvas 逐格采样 → 明度/对比度/饱和度调整 → CIE Lab 最近色匹配；
- 限色：先按使用频率选出前 N 色，再重新映射；
- 抖动：4×4 Bayer 有序抖动 / Floyd–Steinberg 误差扩散；
- 画布：按设备像素比自适应渲染，大尺寸自动降低 DPR 防卡顿；
- 导出：Canvas 离屏合成图纸 + 图例，`toBlob` 下载；
- 全部逻辑原生 JS，无框架、无网络请求。
